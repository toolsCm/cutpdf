# CutPDF ✂️

**CutPDF** es una herramienta web sencilla para **organizar documentos PDF escaneados**, especialmente cuando dos páginas aparecen juntas en una sola hoja, o cuando quieres **separar, recortar y exportar páginas** con facilidad.

🔗 **[Abrir CutPDF](https://toolscm.github.io/cutpdf/)**

## ¿Cómo funciona?

1. **Carga tu PDF.** Elige el archivo y divide sus páginas de forma horizontal o vertical.
2. **Organiza y edita.** Revisa las miniaturas, ajusta recorte, zoom, rotación o márgenes. Activa **Seleccionar** para marcar varias páginas; en computador también puedes usar **Shift** para seleccionar un rango.
3. **Exporta.** Descarga las páginas elegidas en **PDF** o **JPG**. Si exportas **dos o más JPG**, se reúnen automáticamente en un archivo ZIP.

### ¿Para qué sirve?

- Separar páginas dobles de un documento escaneado.
- Recortar bordes o agregar márgenes.
- Elegir solo las páginas que necesitas y descargarlas.

**Sin complicaciones:** carga, ajusta y descarga desde el navegador.
